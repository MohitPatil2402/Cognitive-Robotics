# Robot Demonstration Videos

The following videos demonstrate the successful execution of the robot control tasks implemented in this project.

## Demonstrations

* **Robot Arming and Disarming**

  * Demonstrates enabling and disabling the robot using ROS 2 service calls.

* **Velocity Control**

  * Shows the robot moving forward by publishing `Twist` messages to the `/cmd_vel_nav` topic.

* **Stopping the Robot**

  * Demonstrates both continuous and one-time zero-velocity commands to safely stop the robot.

* **Keyboard Teleoperation**

  * Demonstrates manual robot control using the `teleop_twist_keyboard` package.
